# FIREMESSAGE — Futuristic Monochrome Messenger

> **FireMessage** — ультрасовременный полнофункциональный веб-мессенджер и Progressive Web App (PWA) в эстетике **futuristic 3D + glassmorphism + premium minimalism**. Выполнен в строгой монохромной палитре (исключительно чёрный, белый и нейтральные оттенки серого).

---

## ⚡ Ключевые возможности

1. **Реальный бэкенд на базе Supabase**:
   - Авторизация, сессии и управление профилями через Supabase Auth.
   - База данных PostgreSQL со строгой изоляцией данных через Row Level Security (RLS).
   - Realtime-подписки на новые сообщения, реакции и статусы диалогов.
   - Supabase Storage для аватаров и медиа-вложений (файлы, фото, аудиозаписи).

2. **Личные и групповые чаты**:
   - Мгновенная доставка сообщений в режиме реального времени.
   - Поиск пользователей по `@username` и отображаемому имени.
   - Создание групп с ролями владельца, администратора и участников.
   - Закрепление (Pin) важных диалогов и счетчики непрочитанных.
   - Реакции на сообщения (🖤, ⚡, 👍, 🔥, 👀, 💯).
   - Цитирование (Reply-to), редактирование и удаление собственных сообщений.
   - Индикация набора текста (Typing indicator) с таймаутом.

3. **Медиа и голосовые сообщения**:
   - Запись и воспроизведение реальных голосовых сообщений через браузерный `MediaRecorder` API с динамическим эквалайзером.
   - Отправка изображений с полноэкранным Lightbox-просмотром.
   - Передача документов и файлов с ограничением до 50 МБ и контролем доступа.

4. **WebRTC Аудио- и Видеозвонки**:
   - Реальное P2P соединение между пользователями через `RTCPeerConnection`.
   - Сигнализация (SDP Offer/Answer и ICE Candidates) через защищённый Supabase Realtime Broadcast.
   - Поддержка STUN-серверов Google (`stun:stun.l.google.com:19302`).
   - Управление микрофоном (Mute/Unmute), камерой (On/Off) и переключением фронтальной/задней камеры на мобильных устройствах.
   - Звуковая индикация звонков и входящих сообщений через синтезатор Web Audio API (работает офлайн без сторонних файлов).

5. **PWA (Progressive Web App)**:
   - Установка на Windows, macOS, Android и iOS (Add to Home Screen).
   - Service Worker с предкэшированием ассетов через `vite-plugin-pwa` и Workbox.
   - Офлайн-страница `offline.html` и динамический индикатор сетевого подключения.

6. **Многоязычность (i18n)**:
   - Русский (по умолчанию)
   - Английский (English)
   - Узбекский (O'zbekcha)

## 🚀 Настройка Supabase

### Шаг 1: Создание проекта
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте новый проект.
2. Скопируйте **Project URL** и **anon/public Key** из раздела `Project Settings -> API`.

### Шаг 2: Применение схемы базы данных (Миграция)
1. Откройте **SQL Editor** в вашей панели управления Supabase.
2. Скопируйте и выполните содержимое файла:
   ```
   supabase/migrations/20250101000000_firemessage_schema.sql
   ```
   Этот скрипт автоматически создаст:
   - Таблицы: `profiles`, `conversations`, `conversation_members`, `messages`, `attachments`, `message_reactions`, `user_blocks`, `call_sessions`, `push_subscriptions`.
   - Триггер `on_auth_user_created` для автоматического создания профиля пользователя при регистрации в Supabase Auth.
   - Политики RLS (Row Level Security), запрещающие несанкционированный доступ.
   - Публикации в `supabase_realtime` для таблиц сообщений и диалогов.

### Шаг 3: Настройка хранилища (Supabase Storage)
В SQL Editor выполните содержимое файла:
```
supabase/seed.sql
```
Скрипт создаст:
- Бакет `avatars` (публичный) с политикой загрузки для авторизованных пользователей.
- Бакет `chat-attachments` (приватный) с проверкой членства в диалоге.

### Шаг 4: Конфигурация в приложении
Вы можете указать ключи двумя удобными способами:

1. **Через переменные окружения** (в файле `.env`):
   ```env
   VITE_SUPABASE_URL="https://your-project-id.supabase.co"
   VITE_SUPABASE_ANON_KEY="eyJhbGciOi..."
   ```

2. **Непосредственно в интерфейсе**:
   - Перейдите в раздел **Настройки (Settings)** -> **Подключение к Supabase**.
   - Введите ваш URL и Anon Key.
   - Нажмите **«Применить и проверить»**. Приложение сразу же сохранит ключи в защищенном локальном хранилище и установит соединение!

## 🧪 Тестирование

Тестовый набор Vitest (`src/tests/firemessage.test.ts`) проверяет:
- Валидацию адресов электронной почты и паролей.
- Ограничения на уникальные username (`^[a-zA-Z0-9_]+$`, длина 3–30 символов).
- Санитизацию XSS-инъекций.
- Лимиты на размер вложений (50 МБ).
- Форматирование таймингов, дат и байтов.
- Хранение и сброс конфигурации Supabase.
- Работу контроллера звуковых эффектов.

## 🔒 Безопасность и архитектурные ограничения

1. **WebRTC**: В текущей конфигурации сигнализация вызовов использует открытые STUN-серверы Google. Для работы в сетях со строгими симметричными NAT/Firewall (корпоративные сети, мобильные операторы со строгим CGNAT) в production рекомендуется добавить TURN-сервер (например, Coturn или Twilio Network Traversal).
2. **Push-уведомления**: Приложение запрашивает системные уведомления браузера через Web Notification API, пока вкладка активна или находится в фоновом режиме. Для фоновых push-уведомлений при закрытом браузере требуется подключение внешнего VAPID/WebPush бэкенда.
3. **Хранение секретов**: Client-side код содержит исключительно `anon/public` ключ. Секретный `service_role` ключ никогда не передается на клиент. Все проверки прав производятся базой данных через RLS.
